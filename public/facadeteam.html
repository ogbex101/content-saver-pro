01 — The Problem

Hundreds of panel tasks. No system to track them.

The Facade Team was managing a large-scale facade construction project across multiple elevations of a commercial building — each with dozens of sequential panel fabrication drawing tasks that depended on each other. Without a structured system, there was no clear picture of what was being worked on, what was blocked, or how the overall project was tracking.

Three distinct work areas — the Main Hall, Receipt Bay, and Product Link — were running simultaneously with no shared visibility. Workload was uneven and untracked. Dependencies between tasks were invisible, meaning delays in one drawing cascaded through the whole schedule without warning.

📋
No Structured Timeline

Panel fabrication tasks had no formal start/end dates or dependency links — making it impossible to see what was blocking what.

👥
No Workload Visibility

Three team members were all working across multiple elevations with no way to see who was overloaded or underutilised.

🏗
Three Areas, No Connection

Main Hall, Receipt Bay, and Product Link had no shared system — each was managed separately with no unified view.

📊
No Dashboard or Reporting

No charts, no status tracking, no way to report on overall project health or show clients where things stood.

02 — The Solution

A full monday.com workspace built for facade construction.

A complete monday.com project management system was configured from scratch — tailored specifically to how facade fabrication teams work, with task sequences, elevation-based grouping, dependency links, and a cross-board overview dashboard.

Workspace Structure
  • Main Hall board — primary fabrication board with 4 elevation groups
  • Receipt Bay Hall board — separate board for receipt bay work, Gantt-linked
  • Product Link board — fabrication references and product data
  • Overview Dashboard — connected to all 3 boards simultaneously
  • Holidays board — staff holiday data integrated into timelines
  • Duplicate board — template copy for future project reuse
Gantt & Task Setup
  • Elevation groups — West, North, East, South + Raft Opening Parapet
  • L1–L12 panel sequences — Lower panels → Upper panels, each with date-linked dependencies
  • Grid setup as anchor task for every elevation (all others depend on it)
  • Gantt view with Auto-Fit, Baseline, and Quarters view spanning 2022–2024
  • Timeline column + Duration + Dependent On — full dependency chain visible
  • Person assignment — tasks assigned per team member per elevation
Dashboard & Reporting
  • Pie chart — workload split by person (53.3% / 42.2% / 4.4%)
  • Donut chart — task status breakdown
  • Status categories: Working on it · Done · Stuck · Success
  • Connected to all 3 boards via "3 connected boards" widget
  • Gantt widget on dashboard spanning full project date range
  • People filter — view workload per team member instantly
03 — The Results

Full visibility across every elevation, every task.

The Facade Team now has a single source of truth for the entire project — every panel fabrication task is in the system, every dependency is linked, and the workload dashboard shows at a glance who is doing what and where things stand. The Gantt chart makes it immediately obvious when a task delay will affect downstream work, before it becomes a problem.
